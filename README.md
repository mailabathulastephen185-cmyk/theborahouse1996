# The Bora House 1996 — Loyalty Dashboard

A front-end-only recreation inspired by the publicly observable ReVisit loyalty UI, customized for The Bora House 1996.

## Run
Open `index.html` in a browser.

## Included
- Responsive royal-blue + gold interface
- Dashboard
- Customers
- Visits
- Rewards
- Analytics
- Campaigns
- QR Check-in
- Settings
- Search
- Add customer / visit / reward / campaign modals
- Toast notifications
- Responsive mobile sidebar
- Interactive navigation
- No login page
- No backend/database
